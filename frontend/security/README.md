# SensePath Security Module

## Author

Chunyi Wang

## Role

Testing & Security

## Description

This module provides reusable client-side security validation for SensePath.

Features include:

- Input normalization
- Empty input handling
- Maximum length validation
- Detection of common XSS attack patterns
- Validation before report submission

## Files

securityValidation.js

Reusable security validation functions.

securityTest.js

Unit tests for the validation module.
